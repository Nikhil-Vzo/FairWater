# FairWater - Raipur Smart Water Complaint Portal

FairWater is a full-stack, real-time water monitoring and citizen complaint portal designed for Raipur. It provides a simple, mobile-friendly interface for citizens to report water issues and a powerful, data-rich dashboard for administrators to monitor the city's water infrastructure in real-time.

## Key Features

### Citizen Portal (Homepage: `/`)
* **Simple Complaint Form:** Allows citizens to quickly report issues like "Water Shortage," "Leakage," or "Irregular Supply."
* **Zone Selection:** Users select their zone from a pre-populated list fetched from the database.
* **Image Upload:** Citizens can optionally upload a photo of the issue (e.g., a leak). Images are securely uploaded to Supabase Storage with a preview.
* **Database Integration:** All submitted reports are saved directly to the `citizen_reports` table in Supabase.
* **Contextual Map:** A small, non-interactive map shows the user the general location of the city's water zones, giving them confidence their report is routed correctly.

### Admin Dashboard (Route: `/admin`)
* **Real-time Data Simulation:** A backend service simulates live pressure and flow data for 10 zones, logging this data to the `zone_history` table every 30 seconds.
* **Interactive Map (Leaflet):** Displays all monitoring zones on a map. Clicking a zone selects it, filtering other components.
* **Live Zone Stats:** A dynamic grid of cards shows the *current* pressure and flow for every zone, updating automatically.
* **Historical Data Chart (Recharts):** When a zone is selected, this chart fetches and displays its pressure and flow history from the `zone_history` table.
* **Active Alerts Panel:** This panel is the core of the admin experience. It combines:
    1.  **System Alerts:** Automatically generated by the simulation (e.g., "Low pressure detected in Zone 3").
    2.  **Citizen Reports:** *Immediately* displays new reports submitted from the citizen portal.

    ```sh
    git clone [https://github.com/your-username/fairwater.git](https://github.com/Nikhil-Vzo/fairwater.git)

    ```sh
    cd fairwater

    ```sh

Go to your Supabase project's **SQL Editor** and run the following queries to set up your database.

```sql

);
B. Create citizen_reports Table
This table stores the complaints submitted by users.

SQL

CREATE TABLE citizen_reports (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  issue_type TEXT NOT NULL,
  zone_id TEXT NOT NULL,
  description TEXT NOT NULL,
  image_url TEXT,
  status TEXT DEFAULT 'new' NOT NULL
);
C. Enable Row Level Security (RLS) for Reports
This is critical for security. It allows the public to insert reports but not read, update, or delete them.

SQL

-- 1. Enable RLS
ALTER TABLE citizen_reports ENABLE ROW LEVEL SECURITY;

-- 2. Create a policy to allow public inserts
CREATE POLICY "Allow public insert access"
ON citizen_reports
FOR INSERT
WITH CHECK (true);
D. Create Storage Bucket & Policies
This creates the report_images bucket and allows public uploads.

SQL

-- 1. Create the bucket
INSERT INTO storage.buckets (id, name, public)
VALUES ('report_images', 'report_images', true);

-- 2. Allow public uploads
CREATE POLICY "Allow public uploads"
ON storage.objects
FOR INSERT
WITH CHECK ( bucket_id = 'report_images' );

-- 3. Allow public read access
CREATE POLICY "Allow public read access"
ON storage.objects
FOR SELECT
USING ( bucket_id = 'report_images' );
4. Run the Application
Once all dependencies are installed and your .env and database are configured, run the development server:

Bash

pnpm run dev
